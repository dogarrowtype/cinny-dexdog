# What's New in cinny-dexdog

Enhanced tweaks live in **Settings → Enhancements**.

## On by default

- **Download & Copy buttons** sit under every image and video. Downloads save with the file's *real* name (and the extension comes from the file itself, not whatever it's labelled). Copy works even for WebP/GIF/stickers.
- **Download memory** — a green tick reminds you what you've already saved. Tweak it, forget old saves, or clear it in settings.
- **Caption in one message** — type text, attach one image, send: the text arrives as the image caption instead of a second message. (Spoiler-marked uploads still send the old two-message way, on purpose.)
- **Bigger media** — pictures and videos breathe up to 80% of the window height instead of being clamped small.
- **A wider (or narrower) room list** — drag the edge of the sidebar; double-click to snap back. Narrow it enough and room icons drop out automatically.
- **Reply thumbnails** — quoting a picture shows its picture, not just its filename.
- **Less jank** — the image viewer opens zoomed in (200%), and the "drag files here" overlay no longer gets stuck on screen. It only ever appears for real file drags now.
- **One emoji button** — the composer has a single picker button: click for emoji, Shift+click or right-click for stickers.

## Worth trying (off by default)

- **Save swoop** — a little animation flies the thumbnail into the download button. Purely decorative; try it from Settings.

Everything else (picker that fills the chat pane, bigger reaction emoji, extra name/size knobs) is in the same settings tab. Don't like something? Every feature has its own switch and defaults back to stock Cinny behaviour.
